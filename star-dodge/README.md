# 星域闪避 · Star Dodge

一个跑在浏览器里的竖屏弹幕闪避小游戏。**没有一张素材是"画"出来的**：背景是公有领域的真实天文照片，音乐和音效由 SoundFont 音源现场渲染合成，全部打包在仓库里，离线可玩。

## 直接玩

- 在线（GitHub Pages）：`https://<你的用户名>.github.io/<仓库名>/`
- 本地：仓库根目录起任意静态服务器，例如 `python3 -m http.server`，打开 `http://localhost:8000/`
  （不要直接双击 `index.html`：`file://` 下浏览器会拦掉音频的 CORS 读取，音乐会退回代码合成的兜底版本）

## 玩法

- 触屏拖动移动飞船（拖动是相对位移，手指不会挡住飞船）；桌面端用方向键 / WASD
- 躲弹幕，捡星星；**贴近子弹擦过**有加分，**连捡星星**叠倍率（最高 x5）
- 3 条命：前两次被撞只破盾（1.9 秒无敌），第三次结束
- 每 12 秒进一波：换背景照片、换配色、从第 3 波起换成更快的战斗曲

## 技术

- 纯前端单文件：`index.html`，无构建、无依赖、无框架
- 背景：照片按屏幕比例裁剪烘焙到离屏 canvas，波次切换用双缓冲交叉淡入，`soft-light` 色洗保证弹幕在亮照片上也读得清
- 音频：Web Audio 播放真实录音（循环 BGM 两段交叉淡入 + 事件音效），拿不到文件时退回代码合成的音序器
- 更新用固定步长 1/120 s，粒子与子弹走对象池，DPR 上限 2，切到后台自动暂停
- 所有手感/难度/音量参数集中在 `index.html` 顶部的 `TUNE` 对象里
